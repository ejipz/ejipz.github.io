# 3D Portfolio
A library-themed 3D portfolio where my projects, certificates and experiences take the form of books waiting to be picked up and read. Reading has always been something I have enjoyed so a library felt like a fitting setting for my portfolio. Inspired by [Messenger Abeto](https://messenger.abeto.co/) and [Bruno Simon](https://bruno-simon.com/), whose work showed me how much more interesting a website could be when it becomes something you can actually explore, this project was my excuse to try something a little different and learn Three.js.

*🖥️ Best viewed on desktop*

## Features
- **Catalogue**: Displays all entries at once for visitors who are short on time
- **Real-time Clock Synchronisation**: Window view changes based on the visitor's local time
- **Interactive Furniture**: Chairs and lamps can be interacted with 

## Controls
| Action | Desktop | Mobile |
|---|---|---|
| Move | `W` `A` `S` `D` / Arrow keys | [Left] Virtual joystick |
| Look around | Click and drag | [Right] Swipe |
| Interact | Left click | Tap |
| Close | `Esc` / Click outside or the ✕ button | Tap outside or the ✕ button |
